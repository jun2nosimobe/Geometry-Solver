# 定理カタログ(手書きの部分)

`docs/theorems.html`(Atlas §07 定理)の、コードから作れない部分 ― 各定理の主張を言葉で書いたものと、現状の問題点。
パターン・作図・結論・見積もりの順序・実測はコード(`geom_solver theorem-atlas`)とベンチ(`bench/theorem_stats.sh`)から
`docs/gen_theorem_atlas.py` が作るので、ここには書かない。見出しは定理名(`TheoremDef::name`)と完全に一致させること
(一致しない見出しは生成スクリプトが警告する)。

## 円周角の定理

### 主張
同じ円の上の4点 Apex1・Apex2・Base1・Base2 について、弦 Base1–Base2 を2つの頂点から見込む有向角は等しい:
∠(Apex1 Base1, Apex1 Base2) = ∠(Apex2 Base1, Apex2 Base2)。角の読み方は2つの角で向きをそろえる(向きの組 Cyclic)。

### 問題点
- **規模が上限を超えている**(パターン22)。円の上の4点の順序つきの組を全部舐めるので、点の多い円があると重い(b34)。
- 頂点と底の点を結ぶ4本の直線を**需要として立てる**(`demand_by`)。補助線の需要の主な供給元で、解けている問題の約半分を支える一方、
  円の上の点が増えると需要も組の数だけ増える。
- 結論の角は `build_by` でその場に作る。発火のたびに方向と角が増える(b7)。

## 垂直二等分線の距離の等価性

### 主張
線分 BC の垂直二等分線 PerpMid の上の点 P は、B と C から等距離: PB² = PC²。外心の性質(3本の垂直二等分線が1点で交わる)の証明で使う。

### 問題点
- 中点 Mid_BC と垂直二等分線 PerpMid が**図に既にある**ことを要求する(`match_by`)。垂直二等分線は、逆向きの定理の結論か問題文でしか作られない。
- 直線 BC は需要として立てる。

## 垂直二等分線の距離の等価性の逆

### 主張
B と C から等距離な点 P(PB² = PC²)は、線分 BC の垂直二等分線の上にある。垂直二等分線と中点は前提で要求せず、結論の側で作る。

### 問題点
- 入口は「等しい長さの同値類」の自己束縛で、長さを `build_by` で作る。等しい長さが多い図(円の中心がある図)では組が増える。
- 結論のたびに中点・直線・垂線を作る。図を増やす結論なので、使われない発火は図を膨らませるだけになる。

## 中点連結定理

### 主張
三角形 ABC で AB の中点 M1・AC の中点 M2 について、M1M2 ∥ BC。

### 問題点
- 中点が図に既にあることを要求する(`match_by`)。中点の需要は既定では切っているので、問題文と他の定理の結論にある中点でしか発火しない。
- 直線 BC と M1M2 を需要として立てる。

## 二等辺三角形の底角

### 主張
AB = AC(長さの二乗で)なら、底角が等しい: ∠(AB, BC) = ∠(BC, AC)(向きの組 Isosceles)。

### 問題点
- 3本の辺の直線を需要として立てる。等しい長さの同値類が大きい図では、組の数だけ需要が出る。

## 二等辺三角形の底角の逆

### 主張
底角が等しい(∠(AB, BC) = ∠(BC, AC))なら、AB = AC。自己相似 △ABC ∽ △ACB による古典的な証明に対応する。

### 問題点
- 入口は「等しい角の同値類」の自己束縛。角の同値類が大きい図では、その同値類の定義の組を全部舐める。
- bench_2018chnwesternmop5 の座標を置ける書き方で、局所伝播が作った図形と組むと偽の結論を出した(#75)。この定理そのものの誤りではなく、
  数値的に一致する2点が別の実体のまま残ると退化した三角形で発火する(下の「全体に共通する問題」)。

## 共点二弦の相似(方冪の定理の基礎)

### 主張
2直線 AB・CD が P で交わり、弦 BD を見込む角が ∠(AB, AD) = ∠(CB, CD) なら、△PAD ∽ △PCB から PA·PB = PC·PD(長さの二乗の積)。
円周角の定理と鎖状につながって方冪の定理になる。

### 問題点
- **規模が上限を超えている**(変数21・パターン24)。
- 結論の積(`Product`)を使う定理が今は無い。積は `test_power_of_point` の目標のためにしか使われず、ほかの問題では作るだけになる
  (以前は比の前提で書いたスパイラル相似が使うはずだったが、その前提を作れず一度も発火しなかった。#74)。

## 接弦定理

### 主張
円の上の点 A における接線と弦 AB のなす角は、弦 AB を見込む円周角に等しい: ∠(接線, AB) = ∠(CA, CB)。

### 問題点
- 接線が図に既にあることを要求する(`match_by`)。接線を作る手が無いので、問題文に接線がある問題でしか発火しない。

## 円周角の定理の逆

### 主張
∠(L1, L2) = ∠(L3, L4) で、L1∩L2 = Apex1、L3∩L4 = Apex2、L1∩L3 = Base1、L2∩L4 = Base2 なら、4点は同じ円の上にある
(Apex1・Base1・Base2 を通る円を作り、Apex2 をそれに接続する)。

### 問題点
- 結論のたびに外接円を作る。bench_2018chnwesternmop5 では117個作って、証明に出たのは0個だった(#38)。
- 4点のうち2点が数値的には同じ点なのに別の実体のまま残っていると、2点が重なった退化した外接円を作り、偽の接続を結論する(#75 で観測)。

## 同位角による平行判定(右共通)

### 主張
∠(D1, D3) = ∠(D2, D3)(共通の方向 D3 が右側)なら、方向 D1 と D2 は一致する(平行)。

### 問題点
- 小さく安い。角の同値類の自己束縛から始まる。

## 同位角による平行判定(左共通)

### 主張
∠(D3, D1) = ∠(D3, D2)(共通の方向 D3 が左側)なら、方向 D1 と D2 は一致する(平行)。

### 問題点
- 右共通と同じ。2つに分けているのは、有向角の引数の順序を向きの組で固定しているため。
- **既定設定の全44問でマッチが0回**(右共通は45回・証明に9問)。交替律と右共通で足りていて、要らない可能性がある(未検証。外して選抜で比べる)。

## 有向角の加法性

### 主張
∠(D1, D2) = ∠(D4, D5) かつ ∠(D2, D3) = ∠(D5, D6) なら ∠(D1, D3) = ∠(D4, D6)。

### 問題点
- **角の足し算を規則として総当たりしている**。等しい角の同値類を2つ続けて選び(自己束縛)、その組み合わせを舐めるので、1回の試行が重い
  (上限の到達が多い)。角の等式は有向角の群の上の線形な関係なので、規則ではなく線形代数でまとめて閉じる仕組み
  (AlphaGeometry の AR と同じ発想)に置き換えるのが本筋(#75 の考察、b45)。
- 実測(既定設定・全44問): **全定理の探索量の 23% で最大**。マッチ約3,000回に対し、証明に登場したのは5問。

## 有向角の交替律

### 主張
∠(D1, D2) = ∠(D3, D4) なら ∠(D1, D3) = ∠(D2, D4)。

### 問題点
- 加法性と同じく、角の線形な関係を規則で総当たりしている。

## 直角三角形の斜辺の中線

### 主張
∠(AH, CH) = 90° で M が AC の中点なら、∠(MH, CH) = ∠(CH, CA)(中線 MH と辺の角が等しい = △MHC が二等辺)。

### 問題点
- 入口は直角(Ang90)の同値類。直角が多い図(垂線の多い図)では組が増える。
- 結論のたびに直線 MH・CA とその角を作る。

## 直角三角形の斜辺の中線 (距離版)

### 主張
∠A = 90° で M が BC の中点なら、MA = MB(長さの二乗で)。

### 問題点
- 結論の側で中線の直線と長さを作る。

## 直角三角形の斜辺の中線の逆

### 主張
M が BC の中点で MA = MB なら、∠BAC = 90°。タレスの定理の証明で使う。

### 問題点
- bench_2018chnwesternmop5(元の書き方)では、この定理の結論が数値監査で偽と出る(#75)。この問題は点の座標が置けず監査が当てにならないので、
  真の誤りか誤警報かは区別できていない。

## 中点連結定理(長さ)

### 主張
三角形 ABC の3辺の中点 Mab・Mac・Mbc について、Mab–Mac の長さは B–Mbc(BC の半分)に等しい。

### 問題点
- 3つの中点が全部図にあることを要求する(作らない)。中点は数が少ないので安い。課税は図が大きいときだけ(#63)。

## 中心角の定理

### 主張
O が A・B・C から等距離(外心)なら、中心角 ∠BOC は円周角 ∠BAC の2倍。有向角を円周点との複比 k として評価するので、「2倍」は k² = 積 Product(∠BAC, ∠BAC) で表す。

### 問題点
- 2026-09-28 に既定にした(#70。以前は問題名のリストで bench_2012egmop1 だけに入れていた)。課税はほぼ無いが、ノイズ20の miquel だけ61倍になる。
- 結論の積(角の2乗)を使うのはこの定理自身の結論の側だけ。

## 複比の透視射影不変性(点→線束)/対合定理(共点4直線+横断線)

### 主張
直線 L の上の4点 A・B・C・D と、それらを点 O と結ぶ4直線について、点の複比 (A,B;C,D) = 線束の複比 (OA,OB;OC,OD)。

### 問題点
- 同じ4点の並べ替えを省くため、代表元の番号の昇順(A < B < C < D)の1通りだけを通す。複比は6通りの値を持つので、目標の複比が別の値だと届かない。
  順序を緩めると重くなり、しかもパップス・デザルグ・パスカルは解けなかった(#67)。
- パップス・デザルグでは素の図で一度も発火しない。
- 横断線の上の4点を番号の順序でしか分けておらず、図の上で同じ2点を含む値の定まらない複比で等式を出していた(centroid の以前の解はこれに頼っていた)。
  今は4点と4直線を非退化条件にしている(#81)。pappus は、この定理の等式を代数的な追跡がつないで解ける(#82)。

## 複比の透視射影不変性(線束→点)

### 主張
1点 O で交わる4直線の線束の複比 = それらと横断線 T の交点 Ap・Bp・Cp・Dp の複比。

### 問題点
- 以前は O での共点と T 上の共線を要求しておらず、偽の等式を大量に作っていた(#44 で修正)。
- 線束の複比 `CrossRatioOfLines` を `build_by` で作る。
- centroid では、数値的には同じ直線が別の実体のまま残った線束(4直線のうち2本が一致)で偽の等式を出していた(#76)。

## シュタイナーの定理(二次曲線上の6点の複比不変性)

### 主張
二次曲線の上の点 P1・P5 から、同じ二次曲線の上の4点 P2・P3・P4・Q を見る線束の複比は等しい。円周角の定理の一般の二次曲線への拡張。

### 問題点
- 視点を二次曲線の定義の生成元 P1・P5 に固定した特殊形。別の視点が要るときは、問題の側でその点を生成元に含めて二次曲線を作る必要がある
  (問題の書き方に依存する)。
- パスカルでは一度も発火しない(#67)。

## シュタイナーの定理(接線版)/接弦定理(射影版)

### 主張
シュタイナーの定理で Q → P1 とした極限: P1 における接線と P1 から P2・P3・P4 への直線の線束の複比は、P5 から P2・P3・P4・P1 への線束の複比に等しい。

### 問題点
- 二次曲線が5点の定義で図にあることを要求する。

## シュタイナーの定理の逆(射影版・円周角の定理の逆)

### 主張
2点から4点への線束の複比が等しければ、6点は同じ二次曲線の上にある(5点を通る二次曲線を作り、6点目をそれに接続する)。

### 問題点
- **規模が上限を超えている**(パターン22)。
- 結論のたびに5点を通る二次曲線を作る(bench_2018chnwesternmop5 で16個作って、証明に出たのは0個)。
- 実測(既定設定・全44問): 全定理の探索量の 20%(加法性に次ぐ2位)、マッチ約11,000回で、証明に登場したのは1問だけ。
- 5点のうち3点が共線でも止めなかったので、退化した二次曲線(2直線)に点を載せる偽の結論を出していた。
  centroid では「A が C・G2・Mc(共線)を通る二次曲線の上」が証明に入り、以前の「解けた」はこれに頼っていた(#76)。
  今は、3点が共線な5点の二次曲線は作らない(値の定まらない作図の見送り、#78)。pappus の以前の証明も2直線に退化した二次曲線の上だった。

## 等しい円周角に対する弦は等しい

### 主張
同じ円の上で、2つの弦を見込む円周角が等しければ、弦の長さは等しい。弦² = 4R²sin²θ は θ の符号にも π の周期にも依らないので、
有向角の等式から健全に言える。

### 問題点
- 既定外(`--rules=chord`)。2015 APMO が33万ステップで解けるが、全問題に約25%の課税(#68)。
- 課税の原因は、角の同値類の定義の組(頂点と弦の組)を全部舐めること。合同閉包の局所伝播として、差分評価で書けば安くなる見込み(b35)。

## 平行四辺形の対角線は互いに二等分する

### 主張
対辺が平行な四角形 ABCD(AB ∥ CD かつ BC ∥ DA)では、AC の中点と BD の中点が一致する。

### 問題点
- 既定外(`--rules=parallelogram`)。重心の証明の手順が自力で出るようになる(#68)。
- ノイズ下で平行な直線の組が増えると急に重くなる(ノイズ10で orthocenter が24倍)。

## スパイラル相似(同じ向き)

### 主張
∠(EA, EB) = ∠(ED, EC) かつ ∠(AE, AB) = ∠(DE, DC)(E を通る4直線は相異なる)なら、E を中心とする相似が A→D、B→C に写す。
結論は、中点の対応 ∠(EA, EM) = ∠(ED, EN)・∠(EM, AB) = ∠(EN, DC)(M・N は AB・DC の中点)と、対になる相似の角 ∠(AE, AD) = ∠(BE, BC)。

### 問題点
- 既定外(`--rules=spiral`)。以前は比の前提(EA·EC = EB·ED)で書いていて、その積を作れる定理が無く一度も発火しなかった(#71・#74)。
- 角で書いた今は発火し、bench_2016armog10p2 が補助作図なしで解ける。ただし結論で中点・直線を作るので図が膨らみ、ノイズ下で解けた数を落とす。
  作らない形(局所伝播の「作らない版」)では 2016ARMO が解けない(#75)。
- **規模が上限を超えている**(変数36)。

## 交わる弦の相似(逆向きのスパイラル相似)

### 主張
円に内接する四角形 ABCD の対角線 AC・BD の交点を E とすると、△EAB と △EDC は逆向きに相似(A→D、B→C)。
結論は中点の対応 ∠(EA, EM) = ∠(EN, ED)・∠(EM, AB) = ∠(DC, EN)(M・N は AB・DC の中点で、図に既にあるもの)。

### 問題点
- 2026-09-29 に既定にした(#74)。2011 バルカンが12万ステップで解ける。
- 中点が図に既にあることを要求する(作らない)。中点を作る形にすると、円周上の4点の組ごとに中点・直線・角を作り、無関係な問題が最大14倍重くなった。
- 角の前提で一般に書いた版は、E を通る直線が2本だけの配置で E での角の一致が自明に成り立ち、2直線の交点すべてで点の組を総当たりして重かった。
