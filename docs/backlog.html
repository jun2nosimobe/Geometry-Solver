2026-09-29 ユーザー案: 複比の型をまとめて扱う。 この証明器では有向角は虚円点との複比 (I,J;D1,D2)、点の複比・線束の複比も同じ Scalar で、透視射影不変性・シュタイナーの定理はそれらの間の等式を作っている。角だけでなく複比の型を全部まとめて1つの線形代数で閉じる(複比の対数を取れば、複比の積・商の関係は線形になる。点の複比 = 線束の複比 = 角 の橋渡しを行列の行として持つ)と、角の追跡・複比の追跡・円周角(シュタイナー)の一部が同じ仕組みに載る。数値の対数は要らない(ユーザー指摘): 複比を基本の記号の積・商として形式的に表し、指数だけを持てば関係は線形になる。角は方向ごとの記号 g_D で (I,J;D1,D2) = g_D2 − g_D1、点の複比は有向線分の記号で (A,B;C,D) = s_AC − s_BC − s_AD + s_BD、線束の複比は角の正弦の記号で同様。消去法は指数ベクトルに対して有理数の上で行い、数値(固定座標)は出てきた関係を確かめるのにだけ使う。注意: (1) 直角・調和点列の −1 は「2倍すると0」の元なので、指数の横に符号を mod 2 で持つ(ℚ ⊕ ℤ/2)。(2) 重なった2点の線分は記号にできない ― 記号を作る前に固定座標で0でないことを確かめる(非退化条件、#78 と同じ)。

§04 #78・§04 #79。数値の検算(固定座標)と非退化条件の判定は、前提どおりに自由点を置けて、前提が乱数座標で成り立つ問題でしか使えない。今の44問では8問が外れ(thales・test_right_midpoint など前提を座標への制約として与える問題と、bench_2010g1 のように直線と外接円の両方に乗る自由点を持つ問題)、そこでは偽のマージを止める手段が無い ― bench_2010g1 のノイズ10は、非退化条件で探索の道筋が変わっただけで図の崩壊に当たった。判定不能の一覧(INDETERMINATE_KNOWN)の3問も同じ理由。
案: 法 998244353 の有限体では、判別式が平方剰余なら平方根が取れる(Tonelli–Shanks)。平方剰余になるのは約半分なので、乱数の配置を何回か引き直せば、直線と円・2円の交点を有理的に置ける。前提を座標への制約として与える問題(「OP = OA」など)は、その前提を作図に書き直すか(第2交点・垂直二等分線の上の点など)、同じく拘束を解いて置く。
2026-09-30(§04 #87)に入れた: 平方根だけでなく一般の根を有限体の上で求める(前提を媒介変数の有理関数として標本から復元し、分子の根を gcd で取り出す)。検算専用で、次数の評価(動点法)には使わない(ユーザー方針)。8問中6問(bench_2010g1・thales・test_right_midpoint・test_isosceles_converse・test_steiner_converse・two_circles_reim)で固定座標を置け、どれも解けて偽0。監査の対象は 36 → 42問。残り: test_parallel(前提の担当は最後に作った点 F だが、F では解けず C か D を動かす必要がある)と test_spiral_similarity(1点に前提が3つ)。担当を前の点へ移すと、その前提が後の点にも依存したままになり置く順序と矛盾する ― 複数の点を同時に解くか、前提から解ける点を選ぶ仕組みが要る。

★ 候補capを広げるのが遅すぎる ― 需要作図が尽きるまで待つので、その間に図が膨らむ
行き詰まったときの手は「補助線・交点 → 有向角 → 第2交点 → 中点 → 目標からの逆算 → 候補capの拡大」の順で、候補capの拡大は需要作図が全部尽きてからになる。ところが図が大きいほど需要作図は尽きにくく、cap を広げる番が来る頃には図が膨らみ切っている。
実例(test_spiral_similarity + ノイズ5): 既定では有向角の需要が78回走り、cap は3回広がったものの手遅れで、2,813,981ステップ使って解けない。最初から --fanout-heat-cap=40 にすると 11,014ステップで解ける。--skip-recovery=angle,second,mid(図を広げる手を外す)でも19,891ステップで解ける。
